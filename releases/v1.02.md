# ELAD v1.02 — An S&box import reference

This release gathers what a first real project learned bringing old content into S&box
into one reference, sorted by topic. No skill changed.

## Highlights

- **An S&box import reference.**
  [`examples/sbox/IMPORTING.md`](../examples/sbox/IMPORTING.md) covers what works and what
  doesn't when bringing Source content from Garry's Mod and Half-Life 2, or other games and
  asset packs, into S&box. It's sorted by topic: models, collision, physics and breakables,
  materials and decals, lighting, sound and water, map logic and entities, player movement,
  tools and scripting, and faster ways of working.
- **Each entry says how far to trust it.** It says what to do and what fails and why. It
  ends with its evidence (read in source, seen on a named S&box build, or inferred) and
  the check that proved it, or "nothing yet".
- **A note that S&box is still in development.** The file opens with it. Entries name the
  version they were checked on, and the file ends with steps for rechecking them after an
  S&box update, and for dropping or rewriting an entry when S&box gains a more native way.
- **A format for adding entries,** so any S&box thread can log a lesson as it goes,
  marked general or project-only.
- **Twenty-two entries.** The four from the guide's "Lessons from importing old content"
  moved here, and eighteen are new, from the import of an old Source 1 map on
  `26.10.13a`.

## Compatibility and migration

Nothing in the core breaks. The three skills and the example domain skill are unchanged
since v0.8, and no example script changed.

- **Update your pin.** A project that names its ELAD version changes it to `1.02` and this
  release's commit.
- **Links.** The guide's "Lessons from importing old content" heading stays, pointing to the
  new file, so links to it still resolve.
- **S&box version.** The S&box tools still need S&box `26.10.13` or later.

## Evidence and limits

- **One project, one build.** Every entry comes from one project's import on S&box
  `26.10.13a`, on one Windows machine. S&box citations are at `26.10.13`, which is
  approximate for that build.
- **Source entries cite the SDK, not Garry's Mod.** They read Valve's Source SDK 2013 at
  `be57e3d`. Garry's Mod's fork of Source isn't public, so where an entry describes Garry's
  Mod, the match is inferred unless the entry says it was seen there.
- **Some entries are seen only.** They say so. Several proofs are "nothing yet".
- **No acting-session test ran.** The S&box skill doesn't point to the reference yet;
  that would change what the skill tells agents, so it waits for a pressure test.

## Rollback

Pin `v1.01`. Nothing in a project changes unless its owner adopts v1.02.
