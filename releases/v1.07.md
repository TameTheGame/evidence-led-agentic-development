# ELAD v1.07 — Editor check stops, spec rules for checks and owner input, and more S&box lessons

The fourth batched release. It brings the S&box editor check two early stops and a check on its captures' size, four spec format rules on checks and owner input, a spec lint fix for non-ASCII folders on Windows, and new and extended lessons in the S&box guide and import reference. `tools/check.py` now holds release notes to the form GitHub shows. No skill changed.

## Highlights

- **The editor check stops before it starts an editor that can't work.** [`editor_check.ps1`](https://github.com/TameTheGame/evidence-led-agentic-development/blob/v1.07/examples/sbox/tools/editor_check.ps1) now stops with `NOT RUN` when the project's `.sbproj` sets `AI.EnableMcpCommunication` to `false`, where `sbox-cli` used to wait out its start-up timeout. It refuses a `-Width` or `-Height` outside 16 to 4096 px, which the editor's screenshot tool would clamp without saying so, and fails a capture whose PNG header gives another size than the one asked for. The [rung-1 starter](https://github.com/TameTheGame/evidence-led-agentic-development/blob/v1.07/examples/sbox/rung1-starter/README.md) now says to keep the AI block in the `.sbproj`.
- **Four spec format rules on checks and owner input.** The [spec format guide](https://github.com/TameTheGame/evidence-led-agentic-development/blob/v1.07/docs/SPEC_FORMAT.md) now says that a check a spec cites must run in the project's suite with a planted fault, since a name in the test sources doesn't show anything runs it; that a result line quoting another program's text turns its line breaks into spaces; that a rebuild from a new owner input is compared with a fresh build of it; and that a small owner answer can land as an amendment pinned by its SHA-256, which a later input must carry or say it supersedes.
- **The spec lint works under a non-ASCII folder on Windows.** [`spec_lint.py`](https://github.com/TameTheGame/evidence-led-agentic-development/blob/v1.07/examples/sbox/tools/spec_lint.py) read Git's path for the repository in the ANSI code page, so under a folder whose name is outside ASCII it skipped the owner gate and the retired-ID check with only a note, and passed a changed agreed sentence. It now decodes the path as Python decodes file names.
- **More S&box lessons.** The [S&box guide](https://github.com/TameTheGame/evidence-led-agentic-development/blob/v1.07/examples/sbox/README.md#more-world-build-lessons) now says to read a player's camera only once it has stopped turning, with a limit, a count of the game's frames, and several repeats in one launch; to let `Assert.Inconclusive` through a repeat loop; to bake envmap probes in the editor and keep the bake in Git; to check that a picture check's camera sees what it reads; to take a capture's size from the picture, not the monitor; and that a player's use trace can reach a button behind a thin wall. It adds `Fog` facts on `PostProcessAnchor`, a saved `GradientFog`, the height layer and the sun glow, `TimeSince`'s clock, a `-joinlocal` client and `sbox-cli`'s `-mcp`, and the ending a missing-file warning can carry on `26.10.27c`. The [import reference](https://github.com/TameTheGame/evidence-led-agentic-development/blob/v1.07/examples/sbox/IMPORTING.md#tools-and-scripting) says scripted input for a fixed update needs a `Stage.StartFixedUpdate` hook.
- **Two Windows tooling lessons.** The import reference's [Tools and scripting](https://github.com/TameTheGame/evidence-led-agentic-development/blob/v1.07/examples/sbox/IMPORTING.md#tools-and-scripting) section says that Git Bash rewrites an argument that starts with `/` into a Windows path, so a search for it finds nothing, and that a Python tool's tests run it with a cp1252 pipe and UTF-8 mode off, since a machine that sets `PYTHONUTF8=1` hides code-page bugs.
- **Release notes in the form GitHub shows them.** [`tools/check.py`](https://github.com/TameTheGame/evidence-led-agentic-development/blob/v1.07/tools/check.py) fails the current version's notes when a line carries on the one above it, or when a link is relative or names another tag or a missing file or heading, since GitHub keeps every line break and a relative link breaks on the release page. [Releasing](https://github.com/TameTheGame/evidence-led-agentic-development/blob/v1.07/docs/RELEASING.md#delivery-loop) says to write them that way.

## Compatibility and migration

Nothing in the core breaks. The three skills and the example domain skill are unchanged since v0.8.

- **Update your pin.** A project that names its ELAD version changes it to `1.07` and this release's commit. Search for `1.06` as a whole word.
- **Example scripts.**
  - `editor_check.ps1` keeps its arguments and its exit codes: 0 pass, 1 fail, 2 not run. It now exits 2 before it starts an editor for a `.sbproj` with the AI setting off or a size outside 16 to 4096 px, and 1 for a capture of the wrong size. `-SelfTest` gains eleven cases.
  - `spec_lint.py` keeps its arguments and its output. Under a non-ASCII folder on Windows it now runs the owner gate and the retired-ID check it used to skip, so it can report `NEEDS OWNER` or fail where it passed before. `test_spec_lint.py` gains a case and runs the lint with `PYTHONUTF8=0`.
  - `check_metas.py` changed only in its notes.
- **S&box version.** The S&box tools still need S&box `26.10.13` or later. The `Fog` lessons need `26.10.27`, where `Fog` first appears.

## Evidence and limits

- **One project, one machine.** The lessons and fixes come from one project's work on S&box `26.10.27c`, on one Windows machine. S&box citations read the source at `26.10.13` and `26.10.27`, approximate for that build, which has no source tag yet.
- **Some lessons are read from the source and not run,** among them the fixed-step input entry and the `-joinlocal` lesson.
- **The editor check's new stops and size check** are exercised by planted cases in its `-SelfTest`.
- **The spec lint fix** was shown on Windows, where the new case fails with the old lint and passes with the fix, and on Linux, where the case passes with both.
- **The camera lesson** rests on a part-way read in 2 of 45 runs.
- **No acting-session test ran.** The skill evidence is the same as in v0.8.

## Rollback

Pin `v1.06`. Nothing in a project changes unless its owner adopts v1.07.
