# Synthetic Examples

Every example is original, fictional, and non-operational. Names, hashes, repositories,
workers, evidence, and artifacts do not refer to a real product.

Examples teach protocol boundaries; they do not provide live capability certificates,
adapters, leases, target access, evidence authority, or promotion.

The first example, `two-repository-product/`, shows two product repositories sharing one
protocol and product-wide narrowing risk/data policies while retaining separate
repository authority and evidence delegation. Shared policy never grants either
repository authority. A later release may add isolated candidate, evaluator false-green,
writer-mismatch, lease-conflict, human-claim, and opaque serializer simulations after
their contracts are frozen.

`mixed-claim-semantic-feature/` shows the smaller evaluated path: exact deterministic
claims remain exact while one semantic claim uses a tiny calibrated evaluation loop.
