# Examples

Examples are synthetic and non-normative. They show the method applied to one kind of
project. They grant no authority, and nothing in them refers to a real product's data.

| Example | Shows |
|---|---|
| [`sbox/`](sbox/README.md) | A game map on S&box (Facepunch, Source 2). It includes a spec, the ladder for that target, a working engine-rung test kit, and a target-specific skill. |

Target-specific material lives here, not in the core. Once a project adopts a
target-specific skill, that skill belongs in the project itself.
