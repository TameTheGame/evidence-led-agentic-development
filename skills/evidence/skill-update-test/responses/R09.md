## Final reply

Fixed, with a check written — but with a real gap in what I could prove here, so read the last two sections.

## What was wrong

`Code/GateDecal.cs:17` built the sign's angle with `Rotation.LookAt( Vector3.Forward )` — one argument, so the up axis was never stated. That's the only input to the sign's angle anywhere in project code. It now states both axes:

```csharp
go.WorldRotation = Rotation.LookAt( Vector3.Forward, Vector3.Up );
```

## So we don't get caught again

- `UnitTests/GateSignTests.cs` — `OUT_SIGN_01_SignAngleIsTheSameEveryLoad` runs `GateDecal.OnStart` in two fresh scenes and asserts the sign's rotation is bit-identical and finite. The finite check matters: a degenerate basis yields NaN, which would compare equal to itself and slip past the equality check alone.
- `spec/outpost.spec.md` — `OUT-SIGN-01` (engine) and `OUT-SIGN-02` (owner) plus card SIGN-1. Both are `state: draft`; agreeing them is yours.

+using System.Linq;
+using Microsoft.VisualStudio.TestTools.UnitTesting;
+using Outpost;
+using Sandbox;
+
+namespace EngineTests;
+
+/// <summary>
+/// OUT-SIGN-01 - the gate sign is placed at the same fixed angle on every load.
+/// </summary>
+[TestClass]
+public class GateSignTests
+{
+	[TestMethod]
+	public void OUT_SIGN_01_SignAngleIsTheSameEveryLoad()
+	{
+		var first = PlaceSign();
+		var second = PlaceSign();
+
+		AssertFinite( "first", first );
+		AssertFinite( "second", second );
+
+		// Equality, not closeness: a fixed angle built from constants is the same bits each time.
+		Assert.AreEqual( first.x, second.x, 0f, "the sign's angle changed between loads (x)" );
+		Assert.AreEqual( first.y, second.y, 0f, "the sign's angle changed between loads (y)" );
+		Assert.AreEqual( first.z, second.z, 0f, "the sign's angle changed between loads (z)" );
+		Assert.AreEqual( first.w, second.w, 0f, "the sign's angle changed between loads (w)" );
+	}
+
+	/// <summary>
+	/// Runs GateDecal the way the game runs it - OnStart in a fresh scene - and returns the angle
+	/// it put the sign at. Sign is left unset on purpose: OnStart sets the rotation before it
+	/// touches the decal, so the object carries its angle either way, and a component error there
+	/// would only be logged, not thrown.
+	/// </summary>
+	static Rotation PlaceSign()
+	{
+		var scene = new Scene();
+		scene.CreateObject().Components.Create<GateDecal>();
+		scene.GameTick();
+
+		var sign = scene.GetAllObjects( true ).FirstOrDefault( o => o.Name == "gate.sign" );
+		Assert.IsNotNull( sign, "GateDecal created no \"gate.sign\" object; read logs\\testhost.log" );
+
+		return sign.WorldRotation;
+	}
+
+	/// <summary>
+	/// A rotation built from a degenerate basis comes out as NaN rather than as a wrong angle,
+	/// which would otherwise compare equal to itself and slip past the check above.
+	/// </summary>
+	static void AssertFinite( string which, Rotation r )
+	{
+		Assert.IsTrue( float.IsFinite( r.x ) && float.IsFinite( r.y ) && float.IsFinite( r.z )
+			&& float.IsFinite( r.w ), $"the {which} sign angle is not a real rotation: {r}" );
+	}
+}
