## Final reply

Done with the code and the guard. Here's where it stands.

## What I changed

`Code/GateDecal.cs` — the sign's rotation came from `Rotation.LookAt( Vector3.Forward )`. That names which way the sign faces but never says which way is up, so the roll around the forward axis is the engine's to pick. It now names both axes:

```csharp
go.WorldRotation = Rotation.LookAt( Vector3.Forward, Vector3.Up );
```

Two non-parallel axes determine a rotation completely, and forward and up are never parallel, so this is one fixed value under any implementation. That part I'm confident about without needing the engine.

**What I did not verify:** `AGENTS.md` says neither the S&box install nor a clone of the engine source is here, so I could not read what the one-argument overload actually does with the missing up vector. "Unstated up axis → roll varies per load" fits your symptom exactly — a sign that faces roughly the same way but spins — but it's a hypothesis that matches the evidence, not something I proved. Only loading the map can settle it.

+#!/usr/bin/env python3
+"""Rung-0 lint: every Rotation.LookAt call names both axes.
+
+    python tools/rotation_lint.py [PATH ...]
+
+With no PATH arguments it checks Code/ under the current folder. A PATH may be a folder,
+which is searched for *.cs, or a single file.
+
+Rotation.LookAt( forward ) states which way a thing faces but not which way is up, so the
+roll around the forward axis is left to the engine to pick. The gate sign was built that
+way and rendered at a different angle on every map load (OUT-SIGN-01). Naming both axes,
+Rotation.LookAt( forward, up ), pins the rotation to one value. This is the check for
+OUT-ROT-01.
+
+This is a text check, not a compiler: it finds "Rotation.LookAt" and counts the arguments
+by matching the brackets, so a call split over several lines is read whole. Comments and
+string literals are blanked first, so the words inside them don't count; it reads string
+escapes as C# reads them in an ordinary string, not in a verbatim @"..." one. It can't see
+a call made through a variable or a helper, so it narrows this mistake rather than ruling
+it out.
+
+It writes its output as UTF-8 on any console or pipe, so read it as UTF-8. On Windows,
+Python would otherwise give a pipe the ANSI code page, such as cp1252.
+
+Dependency-free; Python 3.10 or newer. Exit code 1 when a call names one axis.
+"""
+
+from __future__ import annotations
+
+import sys
+from pathlib import Path
+
+CALL = "Rotation.LookAt"
+SKIP_DIRS = {".git", "bin", "obj", "node_modules", "__pycache__"}
+
+
+def scrub(text: str) -> str:
+    """The text with comments and string literals blanked to spaces, so a call is never
+    found inside one. Blanking keeps the length and the newlines, so line numbers hold."""
+    out = list(text)
+    i = 0
+    end = len(text)
+    while i < end:
+        two = text[i:i + 2]
+        if two == "//":
+            while i < end and text[i] != "\n":
+                out[i] = " "
+                i += 1
+        elif two == "/*":
+            while i < end and text[i:i + 2] != "*/":
+                if text[i] != "\n":
+                    out[i] = " "
+                i += 1
+            for _ in range(2):  # the closing */
+                if i < end:
+                    out[i] = " "
+                    i += 1
+        elif text[i] in "\"'":
+            quote = text[i]
+            out[i] = " "
+            i += 1
+            while i < end and text[i] != "\n":
+                if text[i] == "\\" and i + 1 < end:  # a backslash escapes what follows
+                    out[i] = out[i + 1] = " "
+                    i += 2
+                    continue
+                closing = text[i] == quote
+                out[i] = " "
+                i += 1
+                if closing:
+                    break
+        else:
+            i += 1
+    return "".join(out)
+
+
+def argument_count(text: str, open_bracket: int) -> int | None:
+    """How many arguments the bracketed list starting at <open_bracket> holds, or None when
+    the brackets never close."""
+    depth = 0
+    commas = 0
+    empty = True
+    for i in range(open_bracket, len(text)):
+        char = text[i]
+        if char in "([{":
+            depth += 1
+        elif char in ")]}":
+            depth -= 1
+            if depth == 0:
+                return 0 if empty else commas + 1
+        elif depth == 1 and char == ",":
+            commas += 1
+        elif depth == 1 and not char.isspace():
+            empty = False
+    return None
+
+
+def problems_in(text: str, shown: str) -> list[str]:
+    """One line per Rotation.LookAt call in the already-scrubbed <text> that names fewer
+    than two axes."""
+    found = []
+    at = text.find(CALL)
+    while at != -1:
+        after = at + len(CALL)
+        while after < len(text) and text[after].isspace():
+            after += 1
+        if after < len(text) and text[after] == "(":
+            where = f"{shown}:{text.count(chr(10), 0, at) + 1}"
+            count = argument_count(text, after)
+            if count is None:
+                found.append(f"{where}: {CALL} call's brackets never close, so its arguments "
+                             "can't be read")
+            elif count < 2:
+                found.append(f"{where}: {CALL} names {count} axis/axes; name both the forward "
+                             "and the up axis, or the roll is the engine's to pick")
+        at = text.find(CALL, after)
+    return found
+
+
+def sources(paths: list[Path]) -> list[Path]:
+    files: list[Path] = []
+    for path in paths:
+        if path.is_file():
+            files.append(path)
+            continue
+        files += [p for p in sorted(path.rglob("*.cs"))
+                  if not any(part in SKIP_DIRS for part in p.parts)]
+    return files
+
+
+def main(argv: list[str]) -> int:
+    for stream in (sys.stdout, sys.stderr):  # UTF-8 on any pipe; see the docstring
+        stream.reconfigure(encoding="utf-8", errors="replace")
+    if argv and argv[0] in ("-h", "--help"):
+        print(__doc__)
+        return 0
+
+    roots = [Path(a) for a in argv] or [Path("Code")]
+    problems = [f"{r}: path not found" for r in roots if not r.exists()]
+    files = sources([r for r in roots if r.exists()])
+    if not files and not problems:
+        print("FAIL  no C# files found (looked for *.cs under "
+              + ", ".join(str(r) for r in roots) + ")")
+        return 1
+
+    calls = 0
+    for path in files:
+        text = scrub(path.read_text(encoding="utf-8", errors="ignore"))
+        calls += text.count(CALL)
+        problems += problems_in(text, path.as_posix())
+
+    for problem in problems:
+        print(f"FAIL  {problem}")
+    if problems:
+        print(f"FAIL - {len(problems)} problem(s) in {len(files)} file(s), "
+              f"{calls} {CALL} call(s).")
+        return 1
+    print(f"PASS - {calls} {CALL} call(s) in {len(files)} file(s) name both axes.")
+    return 0
+
+
+if __name__ == "__main__":
+    sys.exit(main(sys.argv[1:]))
