## Final reply

Fixed and proven at the engine rung.

**Cause.** `AddMeshBlock` created the `MeshComponent` already enabled and assigned `Mesh` afterwards. Outside an editor scene a `MeshComponent` builds its model — and its collision — only when it becomes enabled, so every mesh block ended up with no collision: all five wall segments, the gate apron, and the tower. The ground still collided because it uses a `BoxCollider`, which is why the floor felt normal while the walls didn't exist. `UnitTests/StarterGeometry.cs:43` already documented the trap; the generator just didn't follow it.

**Fix** (`Code/OutpostGenerator.cs:48`): create the component disabled, assign `Collision` and `Mesh`, then enable it.

**Evidence** — new `UnitTests/OutpostTests.cs` builds the outpost with the real generator from the real `spec/outpost.layout.json`:

- `OUT_COLL_01_EveryFloorHasCollision` — drops a ray onto the ground and onto every block's top face; each must stop at the height the layout states.
- `OUT_COLL_02_EveryWallBlocksAPlayer` — sweeps a `PlayerController` body into each wall from inside the yard; it must be stopped by that wall and never reach its far face.
- `OUT_COLL_02_Control_OpenYardDoesNotBlockAPlayer` — the same sweep across open yard must report clear, so the wall checks can't pass by hitting everything.

Both checks failed before the fix for the right reason (`wall.north did not stop a player walking into it`; `wall.north has no collision: a ray dropped onto its top hit nothing`) and pass after. Full suite: 8/8, no component errors in the engine log.

+	/// <summary>
+	/// A ray dropped from 64 units above <paramref name="surface"/> onto it.

+	static SceneTraceResult DropOnto( Scene scene, Vector3 surface ) =>
+		scene.Trace.Ray( surface + Vector3.Up * 64, surface - Vector3.Up * 8 ).Run();

+	/// <summary>
+	/// A walk into a wall from inside the yard: where the player starts, where it is heading, the
+	/// axis it walks along, and how far along that axis the wall's far face is. The wall is thinnest
+	/// along the axis it blocks, and it faces the yard centre.
+	/// </summary>
+	static (Vector3 Start, Vector3 Target, Vector3 Axis, float FarFace) WalkInto( OutpostLayout.Block wall )
+	{
+		var min = V( wall.Min );
+		var size = V( wall.Size );
+		var centre = min + size / 2;
+
+		// Thinnest axis: the one the wall is meant to block. Walls here are thin in x or y.
+		var thinnest = size.x <= size.y ? Vector3.Forward : Vector3.Left;
+		var thickness = MathF.Min( size.x, size.y );
+
+		// Point the walk from the yard centre towards the wall.
+		var axis = Vector3.Dot( centre, thinnest ) < 0 ? -thinnest : thinnest;
+
+		// Start 96 units short of the wall's near face, standing on the ground, level with the
+		// middle of this wall segment; head 96 units past its far face.
+		var nearFace = Vector3.Dot( centre, axis ) - thickness / 2;
+		var start = (centre - axis * Vector3.Dot( centre, axis ) + axis * (nearFace - 96)).WithZ( min.z + 8 );
+		var target = start + axis * (96 + thickness + 96);
+
+		return (start, target, axis, nearFace + thickness);
+	}
+
+	static Vector3 V( float[] a ) => new( a[0], a[1], a[2] );
