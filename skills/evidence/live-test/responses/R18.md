## Final reply

The test is written in `UnitTests/OutpostTests.cs:18`, and it found something.

## What the test does

`OUT_SPAWN_01_EverySpawnLandsOnSolidGround` loops over every spawn in `spec/outpost.layout.json`, builds the area with the game's own `OutpostGenerator.Build` in a fresh scene per spawn, then drops a headless `PlayerController` at the spawn and ticks until grounded. Three assertions per spawn: it landed, it landed at the right height, and its body isn't inside geometry afterwards.

The expected floor height comes from the layout data, not from the scene the generator built — `ExpectedFloorZ` picks the highest surface the layout puts at or below the spawn (the yard ground, or a block top it stands on). So the generator isn't grading its own output. There's also a guard that fails if the layout lists no spawns, so the loop can't pass vacuously.

`OUT_SPAWN_01_Control_PlayerInsideTowerIsDetected` is the control: a player placed in the middle of the generated tower must be reported as stuck.

A diagnostic run showed `model=null` on all seven generated blocks, a side ray through the tower missing entirely, and only the `ground` box collider stopping anything. The spawn test's "lands on solid ground" is really only testing the ground collider, and its "room to stand" assertion has nothing to be stuck in.

Cause, in `Code/OutpostGenerator.cs:48`: `AddMeshBlock` creates the `MeshComponent` already enabled and assigns `.Mesh` afterwards. `UnitTests/StarterGeometry.cs:43` documents exactly this — outside an editor scene a `MeshComponent` builds only when it's enabled, and setting `Mesh` later does nothing. It fails silently; the engine log has zero component errors. The starter's `Setup_GeneratedMeshBuildsCollision` and its own stuck control both pass with the same box mesh and collision type, differing only in creating the component disabled, assigning the mesh, then enabling it.

I've left the generator alone, since you asked for the test and that one-line change is the root of OUT-COLL-01 as much as this one. Want me to apply it (create disabled → set `Mesh` → `Enabled = true`) and re-run? I'd expect the control to go green and OUT-SPAWN-01 to become a real pass.
