**The test** — `OUT_SPAWN_01_EverySpawnLandsOnSolidGround` builds the area with the real `OutpostGenerator` from `spec/outpost.layout.json`, then for each spawn in a fresh scene: places a headless player, ticks until grounded, and asserts it landed, landed at the height the *layout* says is under it, and isn't inside geometry before or after falling. The expected height comes from `SupportHeight`, computed from the layout data, so the generator doesn't grade its own work — and the loop names the failing spawn, so adding a spawn later is covered without editing the test.

**The control** — `OUT_SPAWN_01_Control_PlayerInsideGeneratedBlockIsDetected` first traces the tower top to prove the generated block has collision at all, then asserts a body inside it is reported. Without that first assertion the two causes are indistinguishable, which mattered here.

**I found and fixed a generator bug in the process.** `Code/OutpostGenerator.cs:48` created `MeshComponent` enabled and assigned `Mesh` afterwards, which silently builds nothing — no exception, no component error in `testhost.log`. Every wall, the gate apron, and the tower had **no collision in a game scene**. A scratch test comparing both orders on the engine:

| Order | `Model` | Trace at tower top (z=480) |
|---|---|---|
| enabled → assign (was) | null | miss, fell through to z=416 |
| disabled → assign → enable (now) | `sbox_procedural_model.vmdl` | hit at z=480 |

The fix is the order `StarterGeometry.CreateBlock:45` and the engine reference both already prescribe. Flagging it because it's a shared code path: it also governs **OUT-COLL-01**, **OUT-ROUTE-01**, and **OUT-SIGHT-01**, whose tests aren't written yet — all three were testing against non-solid geometry.

**Evidence that the check can fail** — I didn't take the green at face value, since both real spawns rest on the `ground` box collider and would pass even with every mesh block missing. Two deliberate breaks:

- The control itself → **red** before the fix (`nothing solid at the top of the generated 'tower' block`), green after.

Both mutations are reverted; `git diff` shows only `Code/OutpostGenerator.cs`, and the layout file is byte-identical. Full suite **7/7 pass**, `spec_lint.py` **PASS**.
