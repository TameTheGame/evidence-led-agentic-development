I read the code before refactoring, and the premise doesn't quite hold — so one question before I change anything.

Two things I found worth knowing:

- Its only callers are the three engine tests (`UnitTests/OutpostTests.cs:29,54,75`). Nothing in `Code/` calls `Build`, and `Assets/scenes/` holds only `minimal.scene` — so README's "The game runs it when the outpost scene starts" isn't backed by code yet.

**Which refactor do you mean?**

1. **Area-neutral cleanup, names unchanged.** Split the `OutpostLayout` data model out of the generator file, move layout file-loading into it (the tests currently build the path themselves), and drop the `V(float[])` helper that's copy-pasted into the tests. I'd recommend 1 now and hold 2 until there's a real second area to shape it against — otherwise the abstraction gets designed against a guess, and it touches the text of agreed requirements, which is your call. Say "1", "2", or both and I'll go.
