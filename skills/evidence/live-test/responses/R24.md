## Final reply

Fixed and proven. Here's what was happening.

## Cause

`Code/OutpostGenerator.cs:48` created the `MeshComponent` **already enabled**, then assigned `Mesh`. In a game (non-editor) scene, `MeshComponent` builds its model only at the moment it's enabled, so assigning the mesh afterwards did nothing — every block came out with no model and therefore **no collision**. It fails silently: the engine logs nothing because nothing threw, the component just quietly does nothing.

Why it showed up "near the gate": the yard's ground is a `BoxCollider`, which worked fine. The one walkable floor built as generated mesh is `gate.apron` — the slab just outside the gate (y −1024…−800). So that was the only patch of floor with nothing under it, and players walking out the gate dropped through.

The repo already documented this gotcha in `UnitTests/StarterGeometry.cs:43-48`; the generator just didn't follow it. No new engine lesson needed — the fix carries the comment.

**The bigger find:** the walls and the tower had no collision either. The tester only noticed falling because the apron is the only mesh *floor*; players could also have walked straight through every wall and through the tower.

## Fix

Create the component disabled, assign, then enable — matching `StarterGeometry.CreateBlock`.

+	/// <summary>
+	/// Points across a floor's top face: both edges plus a grid between them, inset so a sample
+	/// never lands exactly on a seam. Points under an obstruction are skipped.
+	/// </summary>
+	static IEnumerable<Vector2> SamplePoints( Floor floor, List<(Vector2 Min, Vector2 Max)> obstructions )
+	{
+		const float step = 64f, inset = 8f;
+
+		foreach ( var x in Axis( floor.Min.x, floor.Max.x, step, inset ) )
+			foreach ( var y in Axis( floor.Min.y, floor.Max.y, step, inset ) )
+			{
+				var point = new Vector2( x, y );
+				if ( !obstructions.Any( o => Covers( o, point, inset ) ) )
+					yield return point;
+			}
+	}
+
+	/// <summary>Inset positions along one axis, on the given pitch, always including both ends.</summary>
+	static IEnumerable<float> Axis( float min, float max, float step, float inset )
+	{
+		var low = min + inset;
+		var high = max - inset;
+
+		if ( high < low )
+			yield break;
+
+		for ( var value = low; value < high; value += step )
+			yield return value;
+
+		yield return high;
