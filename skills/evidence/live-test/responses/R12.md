## Final reply

Done. Both the check and its control are in `UnitTests/OutpostTests.cs`.

```
OUT-SPAWN-01  engine   pass   working tree (uncommitted; base 3b76d2f)
```

**The test** (`OUT_SPAWN_01_EverySpawnLandsOnSolidGround`) builds the outpost with the game's own `OutpostGenerator.Build` from `spec/outpost.layout.json` — not stand-in geometry — then, for every spawn in the layout in a fresh scene: ticks until grounded, asserts it landed at the layout's ground top (z = 0, ±tolerance), and asserts the body isn't inside geometry afterwards. Expected values come from the layout data, and it asserts the spawn list is non-empty so an empty loop can't pass silently.

**The control** (`OUT_SPAWN_01_Control_PlayerInsideTowerIsDetected`) puts a player inside the generated tower and requires the stuck check to report it — otherwise the main test's pass says nothing about room to stand.

**The control caught a real generator bug.** It failed first time: the tower mesh had built no model, and the engine log showed no component error — nothing threw, the mesh assignment simply did nothing. Cause at `Code/OutpostGenerator.cs:48`: `MeshComponent` was created **enabled** and `Mesh` assigned afterwards. In a game (non-editor) scene a `MeshComponent` builds its model only when it is enabled, so every wall, the gate apron and the tower had **no collision at all** — in the running game too, not just in tests. The contrast pins it: `Setup_GeneratedMeshBuildsCollision` builds the identical box mesh via create-disabled → assign → enable and gets its collision mesh.

So I made the matching one-line change in the generator — create disabled, assign, then enable — which is inside what OUT-SPAWN-01 lists as its touches (generator code). Full suite is now 7/7 green and `py -3 tools/spec_lint.py` passes with no spec change. Revert that hunk if you'd rather it land as part of OUT-COLL-01.

Two things this does **not** prove: OUT-COLL-01 (that every walkable floor has collision) still needs its own test — my control only proves the tower built; and nothing here speaks to how the outpost looks or feels. I haven't committed anything.
