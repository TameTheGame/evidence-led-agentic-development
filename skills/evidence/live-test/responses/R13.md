## Final reply

Done — `Code/OutpostGenerator.cs` refactored, behaviour unchanged.

**What changed**

- **Split the data model out.** `OutpostLayout` (the layout-file contract, read by both the generator and the tests) moved to a new `Code/OutpostLayout.cs`. The generator file is now only the builder, and no longer needs `System.Text.Json`/`System.Collections.Generic`.
- **Shared the common step.** `AddGround` and `AddMeshBlock` both began with create-object / name-it / position-it; that's now one `NewObject( scene, name, position )` helper.
- **Dropped the unused returns.** Both `Add*` helpers returned a `GameObject`/`MeshComponent` that `Build` discarded; they're `void` now.
- **Wrote down the two non-obvious bits** rather than "fixing" them, since both are deliberate: why the ground object sits at the box's centre while mesh blocks sit at their `min` corner (a `BoxCollider` is centre-anchored), and why the `MeshComponent` is created disabled and enabled last (enabling is what builds the model and collision).

Net: `Code/OutpostGenerator.cs` 102 → 86 lines, 19 insertions / 35 deletions, plus the new 27-line model file.

**Evidence**

- `tools/run_engine_tests.ps1` — Total 8 / Passed 8, 0 component errors (includes OUT-COLL-01, OUT-SPAWN-01 and its control, which drive `OutpostGenerator.Build` directly).
- `py -3 tools/spec_lint.py` — PASS, 9 requirements well formed, no agreed requirement changed.
- `UnitTests/` is untouched on purpose, so the existing checks acted as an unchanged oracle for the change.

**Two things for you to decide**

1. If "the generator every area uses" meant you want it turned into a *shared, area-agnostic* generator (e.g. `AreaGenerator` taking any area's layout), that's a different and much larger change, and I didn't do it — the outpost is the only area today, so it would be an abstraction built for callers that don't exist. Say the word if that's the direction and I'll do it.
2. Minor leftover duplication: `static Vector3 V( float[] a )` now exists in both the generator and `UnitTests/OutpostTests.cs:19`. It could become `Vector3` accessors on the layout model and remove both, but that edits the tests, so I left it for a separate pass.
