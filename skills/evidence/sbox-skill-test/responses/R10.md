## Final reply

Fixed the generator; the evidence for it has to come from you, because this environment has no S&box install.

**Root cause** — `Code/OutpostGenerator.cs:48`. `Components.Create<MeshComponent>()` enables the component immediately, and in a game scene a `MeshComponent` builds its model *when it is enabled*, ignoring `Mesh` and `Collision` set afterwards. So every block was built as an empty model with no collision shapes. The ground still worked because `BoxCollider` rebuilds on property change, which is why only the generated walls, apron and tower are walk-through.

**The fix** — create the component disabled, set `Collision` and `Mesh`, then enable:

```csharp
var block = go.Components.Create<MeshComponent>( false );
block.Collision = MeshComponent.CollisionType.Mesh;
block.Mesh = BoxMesh( size );
block.Enabled = true;
```

+[TestClass]
+public class CollisionTests
+{
+	/// <summary>
+	/// OUT-COLL-02 — every generated block stops a trace aimed at it.
+	///
+	/// Mesh collision is a hollow surface, so each ray starts outside the block and crosses
+	/// its nearest face along the block's thinnest axis. A block whose MeshComponent built
+	/// an empty model (mesh assigned after the component was enabled) is missed entirely,
+	/// which is the failure this test exists for.
+	///
+	/// Needs a loaded "default" physics surface: base content isn't mounted headlessly and
+	/// PolygonMesh.Rebuild() throws in ModelBuilder.AddSurface without one. Register the
+	/// stand-in from the engine-rung spike kit (TestSurfaces.cs) in test setup first.
+	/// </summary>
+	[TestMethod]
+	public void OUT_COLL_02_EveryBlockCollides()
+	{
+		var scene = new Scene();
+		using var scope = scene.Push();
+
+		var layout = OutpostLayout.Parse( File.ReadAllText( LayoutPath() ) );
+		OutpostGenerator.Build( scene, layout );
+		scene.GameTick();
+
+		foreach ( var block in layout.Blocks )
+		{
+			var min = new Vector3( block.Min[0], block.Min[1], block.Min[2] );
+			var size = new Vector3( block.Size[0], block.Size[1], block.Size[2] );
+			var centre = min + size / 2;
+
+			// Aim down the thinnest axis: the shortest unobstructed line into the block.
+			var axis = size.x <= size.y && size.x <= size.z ? new Vector3( 1, 0, 0 )
+				: size.y <= size.z ? new Vector3( 0, 1, 0 )
+				: new Vector3( 0, 0, 1 );
+			var reach = axis.Dot( size ) / 2 + Standoff;
+
+			var result = scene.Trace.Ray( centre - axis * reach, centre + axis * reach ).Run();
+
+			Assert.IsTrue( result.Hit, $"nothing blocked a trace through block \"{block.Id}\"" );
+			Assert.AreEqual( block.Id, result.GameObject?.Name,
+				$"the trace through block \"{block.Id}\" hit something else first" );
+		}
+	}
+
+	/// <summary>How far outside a block each ray starts, in world units.</summary>
+	const float Standoff = 64;
