## What it does

Builds the scene with `OutpostGenerator.Build` from `spec/outpost.layout.json`, then asks the physics world about each spawn — three traces per spawn, not the generator's own bookkeeping:

1. **Spawn point clear** — a zero-length standing-hull box test at the spawn. A player buried in a wall never gets to fall anywhere.
2. **Solid ground below** — a ray down to the bottom of the layout bounds must hit something.
3. **Room to stand where it lands** — the same hull test at the landing point, lifted 1 unit so the floor it rests on doesn't count as being in the way.

The hull is 32×32×72 (`PlayerController`'s radius 16, height 72), feet at the trace point. It also asserts the layout lists at least one spawn, so an empty `spawns` array can't pass vacuously. The layout file is found by walking up from the test binaries, so no csproj change is needed to copy it.
