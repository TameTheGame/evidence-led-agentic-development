## How it settles the requirement

"Every spawn lands on solid ground with room to stand" is two claims, and the outpost's two collider kinds need different probes. The ground is a solid `BoxCollider`; the walls, apron and tower are `MeshComponent` blocks, whose collision is a **hollow surface** — a body wholly inside one touches no face, and traces don't see mesh faces from behind. So an overlap test alone is blind to a spawn buried in a wall. Three probes per spawn:

| Probe | Catches | Nothing else catches it |
|---|---|---|
| `AssertSolidGroundBelow` | spawn floating, or over a hole | falling on spawn |
| `AssertNotInsideSolidCollider` | spawn sunk into the yard ground | `StartedSolid` only fires for the solid box |
| `AssertStandingColumnClear` | spawn inside/under a block, or too close to a wall for its width | the hollow-mesh blind spot |

The player's standing size is the test's own fixture (72 × 16) rather than read from `PlayerController`, so the expected answer doesn't come from the code under test.

## Two guards against a pass that means nothing

- **A vacuous "every spawn".** An empty spawn list would pass without checking anything, so the count is asserted first.
- **Geometry that silently isn't there.** This is the important one. `MeshComponent` errors are caught and logged, not thrown — if mesh collision never builds, the column probe sails through walls and the test goes **green for the wrong reason**. So `AssertProbedGeometryExists` probes the ground and `wall.north` before any spawn is tested, and fails with the two known causes and a pointer to `logs/testhost.log`.
