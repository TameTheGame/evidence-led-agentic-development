## Final reply

**Rigor: bounded** — a one-value data change with an ordinary revert, but the claim itself is runtime behaviour I can't check in this environment, so it ships with a static check and an owner card rather than a verified pass.

## What the layout data says

Resolving every block to `min`…`min+size`:

| piece | x | y | top z |
|---|---|---|---|
| `ground` | -800 … 800 | **-800** … 800 | 0 |
| `gate.apron` | -96 … 96 | -1024 … **-800** | 0 |
| `wall.south.west` | -800 … **-64** | -800 … -768 | 192 |
| `wall.south.east` | **64** … 800 | -800 … -768 | 192 |

The yard floor ends at `y = -800` and the apron floor begins at `y = -800`. They **butt together with exactly zero overlap** — two separate colliders (the yard is a `BoxCollider`, the apron is mesh collision) meeting on a single plane, with no overlap for the solver to resolve at the join.

Everywhere else along that line a wall stands on it, so players can't get to it. The only reachable stretch is the 128-unit gate gap, `x` -64 … 64. **The one place in the whole outpost where a player walks across a zero-overlap floor join is the gate mouth** — which is where the tester fell.

## The fix

`spec/outpost.layout.json` — apron `size.y` 224 → 256, so it runs `y` -1024 … -768 and overlaps the yard floor by 32 units. Its top stays at z=0, so there's no step. The extra 32 units sit inside the wall bases at `x` ±64…±96 and show as a 128×32 strip in the gate mouth.

I also added `tools/layout_lint.py` (static rung) and `OUT-COLL-02` to the spec as **draft**, so this can't come back silently. Its rule: same-height floor faces that touch without overlapping, or leave a gap narrower than a player (32 units), fail. Wider openings like the gate itself are left alone. `py -3 tools/spec_lint.py` → `PASS — 10 requirements well formed; no agreed requirement changed since HEAD`.

## Two things I could not settle

**The apron is an isolated platform.** South of `y = -800`, the apron is the *only* floor. Its east and west edges at `x = ±96` have nothing beyond them and no railing — step sideways just outside the gate and you drop. That's also "near the gate", and what to do about it is a design call, not a bug fix.

**The apron may have no collision at all.** It's the only player-walkable floor built as a `MeshComponent`, and in `Code/OutpostGenerator.cs:49-50` `Collision` is assigned *before* `Mesh`. If the component builds its physics shape when `Collision` is set, that shape comes from an empty mesh — which produces exactly this report. I deliberately left the code alone: `OUT-COLL-01` settles it with evidence, and changing both at once would hide which one mattered.

+#!/usr/bin/env python3
+"""Rung-0 lint for the outpost layout data.
+
+    python tools/layout_lint.py [LAYOUT]
+
+With no LAYOUT argument it checks spec/outpost.layout.json.
+
+OUT-COLL-02 — walkable floor pieces overlap where they meet. Two floor surfaces at the
+same height that only touch edge to edge, or that leave a sliver of a gap, fail the run
+(exit code 1). A butt joint gives the physics solver no overlap to resolve at the join,
+and a sliver is an outright hole; either can drop a player through the floor.
+
+Openings wider than SLIVER are left alone, so a real doorway such as the gate is not a
+finding. SLIVER is narrower than a standing player, so a gap that small can only be a
+mistake.
+
+This is the static rung. It reads the data file only: it cannot say whether the generator
+actually built collision for a piece, or how a moving player behaves at a join. Those are
+engine-rung claims (OUT-COLL-01).
+
+Dependency-free; Python 3.10 or newer.
+"""
+
+from __future__ import annotations
+
+import json
+import sys
+from pathlib import Path
+
+SLIVER = 32.0  # units; narrower than a standing player
+
+
+class Surface:
+    """The upward-facing face of a box, as a rectangle at one height."""
+
+    def __init__(self, sid: str, x0: float, x1: float, y0: float, y1: float, top: float):
+        self.id, self.x0, self.x1, self.y0, self.y1, self.top = sid, x0, x1, y0, y1, top
+
+    def __str__(self) -> str:
+        return f"{self.id} x[{self.x0:g},{self.x1:g}] y[{self.y0:g},{self.y1:g}] z={self.top:g}"
+
+
+def surfaces(layout: dict) -> list[Surface]:
+    """The top face of the ground and of every block."""
+    found = []
+    ground = layout["ground"]
+    gmin, gmax = ground["min"], ground["max"]
+    found.append(Surface("ground", gmin[0], gmax[0], gmin[1], gmax[1], gmax[2]))
+    for block in layout["blocks"]:
+        low, size = block["min"], block["size"]
+        found.append(Surface(block["id"], low[0], low[0] + size[0],
+                             low[1], low[1] + size[1], low[2] + size[2]))
+    return found
+
+
+def overlap(a0: float, a1: float, b0: float, b1: float) -> float:
+    """Overlap of two spans: positive when they share length, negative when apart."""
+    return min(a1, b1) - max(a0, b0)
+
+
+def joins(found: list[Surface]) -> list[str]:
+    """OUT-COLL-02 findings: same-height faces that touch without overlapping."""
+    problems = []
+    for i, a in enumerate(found):
+        for b in found[i + 1:]:
+            if a.top != b.top:
+                continue  # a join between different heights is a step, not a seam
+            x, y = overlap(a.x0, a.x1, b.x0, b.x1), overlap(a.y0, a.y1, b.y0, b.y1)
+            if x > 0 and y > 0:
+                continue  # they overlap: nothing to fall through
+            for gap, along, axis in ((x, y, "x"), (y, x, "y")):
+                if along <= 0:
+                    continue  # no shared edge on the other axis: not a join at all
+                if gap == 0:
+                    problems.append(f"{a.id} and {b.id} butt together along {axis} at z={a.top:g} "
+                                    f"with no overlap ({along:g} units of shared edge)")
+                elif -SLIVER < gap < 0:
+                    problems.append(f"{a.id} and {b.id} leave a {-gap:g}-unit gap along {axis} "
+                                    f"at z={a.top:g} ({along:g} units of shared edge)")
+    return problems
+
+
+def main(argv: list[str]) -> int:
+    sys.stdout.reconfigure(errors="replace")
+    path = Path(argv[0]) if argv else Path("spec") / "outpost.layout.json"
+    if not path.is_file():
+        print(f"FAIL  {path}: file not found")
+        return 1
+    layout = json.loads(path.read_text(encoding="utf-8"))
+
+    found = surfaces(layout)
+    print(f"{path.as_posix()}: {len(found)} top faces")
+    for surface in sorted(found, key=lambda s: (s.top, s.id)):
+        print(f"  {surface}")
+
+    problems = joins(found)
+    for problem in problems:
+        print(f"FAIL  OUT-COLL-02: {problem}")
+    if problems:
+        print(f"FAIL — {len(problems)} floor join(s) a player could drop through.")
+        return 1
+    print("PASS — every floor join overlaps.")
+    return 0
+
+
+if __name__ == "__main__":
+    sys.exit(main(sys.argv[1:]))
