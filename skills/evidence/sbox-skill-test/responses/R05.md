## What I changed

**`Code/OutpostGenerator.cs`** — each generated block now gets its own `BoxCollider`, static, sized to the block. That's the same component that already makes the ground solid in this file, so wall collision no longer depends on `MeshComponent`'s collision generation at all. To do that without an offset, the block's mesh is now centred on its object instead of corner-at-origin, and the object sits at the box centre — matching how the ground is placed. The `MeshComponent` and its `Collision = Mesh` are untouched, so if that path *was* partly working the change is purely additive; the two shapes are the same static box.

+
+	/// <summary>How close a hit has to be to the expected surface height, in units.</summary>
+	const float Tolerance = 1;

+	[TestMethod]
+	public void OUT_COLL_01_EveryFloorHasCollision()
+	{
+		var layout = Layout();

+		using var scope = scene.Push();
+		OutpostGenerator.Build( scene, layout );

+		// The yard floor.
+		var groundMin = V( layout.Ground.Min );
+		var groundMax = V( layout.Ground.Max );
+		AssertSolidFromAbove( scene, "ground", new Vector3(
+			(groundMin.x + groundMax.x) / 2, (groundMin.y + groundMax.y) / 2, groundMax.z ) );
+
+		// Every block's top face, which includes the gate apron players walk in over.
+		foreach ( var block in layout.Blocks )
+		{
+			var min = V( block.Min );
+			var size = V( block.Size );
+			AssertSolidFromAbove( scene, block.Id, new Vector3(
+				min.x + size.x / 2, min.y + size.y / 2, min.z + size.z ) );
+		}
+	}
