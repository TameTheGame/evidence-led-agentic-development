## Root cause

`Code/OutpostGenerator.cs` created the `MeshComponent` already enabled, then assigned the mesh:

```csharp
var block = go.Components.Create<MeshComponent>();   // enabled here
block.Collision = MeshComponent.CollisionType.Mesh;
block.Mesh = BoxMesh( size );                        // too late
```

In a game (non-editor) scene a `MeshComponent` builds its model only when it is enabled. Every block was therefore enabled with a null mesh, built nothing, and got no collision; assigning `Mesh` afterwards did nothing. The ground is unaffected because it uses a `BoxCollider` — which is exactly why players stand on the floor but pass through walls, the gate apron, and the tower.

The fix is the create-disabled / assign / enable order, with a comment at the site so it doesn't get re-broken. I also checked the box mesh's face winding by hand — all six faces have outward normals, so the geometry wasn't the problem.
