## Final reply

Done. The mesh-block code now lives in its own class.

**`Code/MeshBlock.cs`** (new) — `public static class MeshBlock` in namespace `Frontier`:
- `Create( scene, id, min, size )` — the former `AddMeshBlock`, now public since the generator calls it from outside.
- `BoxMesh( size )` — moved unchanged, kept private as nothing else uses it.

**`Code/AreaGenerator.cs`** — both methods removed; the block loop now calls `MeshBlock.Create(...)`. The generator keeps `AddGround` and the `V` array helper. The "Walls, cliffs, aprons, docks, and landmarks all use this" note moved up to the new class summary, where it describes the class rather than one method.

**`README.md`** — the code-layout bullet names the new file, since it listed `AreaGenerator.cs`.

The code itself is a byte-for-byte move; only the name and the doc-comment placement changed.

Checks:
- `py -3 tools/spec_lint.py` — PASS, 13 requirements well formed, no agreed requirement changed.
- `tools/run_engine_tests.ps1` — 11/11 passed, 0 component errors. These build both the outpost and the quarry through `AreaGenerator.Build` and trace collision against the generated blocks, so they exercise the moved code end to end rather than just compiling it.

One thing I left alone deliberately: `UnitTests/StarterGeometry.cs` has a near-identical copy of this code (`Box` + `CreateBlock`). It's now redundant with `MeshBlock`, but its own comment says it's a stand-in for the starter tests — pointing it at the game's class would couple the engine-setup checks to game code, which is the opposite of what it's for. Say the word if you'd rather collapse the two anyway.

+/// <summary>
+/// Makes the static mesh boxes an area is built from. Walls, cliffs, aprons, docks, and

+	/// its lowest corner in world space.
+	/// </summary>
+	public static MeshComponent Create( Scene scene, string id, Vector3 min, Vector3 size )
+	{
+		var go = scene.CreateObject();
+		go.Name = id;
+		go.WorldPosition = min;
+
+		var block = go.Components.Create<MeshComponent>( false );
+		block.Collision = MeshComponent.CollisionType.Mesh;
+		block.Mesh = BoxMesh( size );
+		block.Enabled = true;
+
+		return block;
+	}
+
+	/// <summary>
+	/// An axis-aligned box mesh with one corner at the local origin.
+	/// </summary>
+	static PolygonMesh BoxMesh( Vector3 size )
+	{
+		var mesh = new PolygonMesh();
