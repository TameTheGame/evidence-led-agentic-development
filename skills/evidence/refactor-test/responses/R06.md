## Final reply

Done. The mesh-block code now lives in its own class.

**What moved** — `Code/MeshBlock.cs` (new), namespace `Frontier`:
- `MeshBlock.Create( scene, id, min, size )` — the old private `AddMeshBlock`, now public since it's the shared piece both areas' blocks go through.
- `BoxMesh( size )` — stays private inside `MeshBlock`; nothing outside used it.

Bodies are byte-identical to the originals, so block geometry, collision type, and the create-disabled-then-enable order are unchanged.

**What stayed** in `Code/AreaGenerator.cs:11`: `Build`, `AddGround`, and the `V` float-array helper. The one call site is now `MeshBlock.Create(...)`.

README's file list got a clause pointing at the new file.

**Checks** (both run after the change):
- `py -3 tools/spec_lint.py` → PASS, 13 requirements well formed, no agreed requirement changed.
- `& ./tools/run_engine_tests.ps1` → 11/11 passed, 0 distinct component errors. This also compiles the project, so it confirms the move builds. The 14 other engine-log error lines are the usual headless start-up noise (missing shaders), present on passing runs.

One thing I left alone deliberately: `UnitTests/StarterGeometry.cs:14` has a near-identical `Box`/`CreateBlock` pair, and its own doc comment says it's stand-in geometry for the rung-1 starter tests rather than the project's generator. Folding it into `MeshBlock` would couple the starter's setup checks to game code they're meant to be independent of, so that's a separate call if you want it made.

+namespace Frontier;

+/// <summary>
+/// A static box of generated mesh geometry with mesh collision. Walls, cliffs, aprons, docks,
+/// and landmarks all use this.
+/// </summary>
+public static class MeshBlock
+{
+	/// <summary>
+	/// Creates a block in <paramref name="scene"/>. <paramref name="min"/> is its lowest corner
+	/// in world space.
+	/// </summary>
+	public static MeshComponent Create( Scene scene, string id, Vector3 min, Vector3 size )
+	{
+		var go = scene.CreateObject();
+		go.Name = id;
+		go.WorldPosition = min;
+
+		var block = go.Components.Create<MeshComponent>( false );
+		block.Collision = MeshComponent.CollisionType.Mesh;
+		block.Mesh = BoxMesh( size );
+		block.Enabled = true;
+
+		return block;
+	}
+
+	/// <summary>
+	/// An axis-aligned box mesh with one corner at the local origin.
+	/// </summary>
+	static PolygonMesh BoxMesh( Vector3 size )
+	{
+		var mesh = new PolygonMesh();
+		var v = mesh.AddVertices(
+			new Vector3( 0, 0, 0 ), new Vector3( size.x, 0, 0 ),
+			new Vector3( size.x, size.y, 0 ), new Vector3( 0, size.y, 0 ),
+			new Vector3( 0, 0, size.z ), new Vector3( size.x, 0, size.z ),
+			new Vector3( size.x, size.y, size.z ), new Vector3( 0, size.y, size.z ) );
+
+		mesh.AddFace( v[0], v[3], v[2], v[1] ); // bottom
+		mesh.AddFace( v[4], v[5], v[6], v[7] ); // top
