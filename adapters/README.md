# Adapter Boundary

No adapter is implemented in Level 0.

Future adapters translate the provider-neutral protocol to an exact harness or transport.
They do not grant tools or authority and may expose only registered logical operations.

- Different orchestrator, worker, and product-inference harnesses require distinct
  qualification subjects even when they load the same model weights.
- MCP or CLI/JSON is a transport choice, not an authority model.
- Real target facades stay target-local.
- Arbitrary shell, filesystem, process, package, Git, secret, or publication gateways are
  forbidden.
