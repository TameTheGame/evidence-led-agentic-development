# Promotion Design Placeholder

Promotion is intentionally not part of the executable Level 0 schema set.

Before implementation, freeze a proposal that covers:

- fresh owner authority, writer profile, capability certificate, packet, and fenced
  promotion surface;
- exact accepted candidate, evidence, verifier, and external-human receipt identities;
- target divergence and unrelated-work preservation;
- required promotion-time evaluators and deliberate negatives;
- stale/replay/partial/ambiguous promotion refusal;
- rollback and downstream invalidation;
- separation from publication.

Then run malicious fixtures and independent adversarial review. Do not extend a candidate
worker packet or lease into promotion.
